## <img src="https://raw.githubusercontent.com/MoXiao528/AIDetector-web/main/public/favicon.svg" width="28" height="28" alt=""> RepreGuard

These days I'm working on **RepreGuard-AIDetector**, a tool for detecting AI-generated text across languages. I build the web interface and the API that connects it to the detection service.

In the web app, you can upload a document, see which passages the detector flags, and export the results as a PDF.
